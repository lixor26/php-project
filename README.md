Stock Manager is a web-based inventory management system built with PHP, MySQL and Bootstrap. It helps small businesses manage their customers and suppliers, record purchases and sales, track live stock levels, and generate GST invoices (CGST + SGST).

Features:
- User registration, login and OTP-based password reset
- Dashboard with today's purchases and sales, low-stock and expiry alerts
- Customer and supplier management with photos
- Purchase and sale entries with batch number, expiry date and GST
- Printable sale invoices
- Stock overview with filters, and full purchase and sale history
- Every user has their own private data, and a new user starts with an empty account
